# Fuseo for Windows 使い方ガイド

本人確認書類の写真や控除証明書などの PDF の、見せなくてよい欄を黒く塗って、復元できない形の提出用コピーにするツールです。
無料・オープンソース（MIT）。書類はこのパソコンの中だけで扱い、どこにも送信しません（通信機能がありません）。

- Mac 版・iPhone 版の使い方は [使い方ガイド（トップ）](user-manual.md) から
- 画面つきの機能の紹介は「[機能のご紹介](https://fuseo.ati-mirai.co.jp/features.html)」（「Windows」を選ぶと Windows の画面になります）

動作環境: Windows 10（1809 以降）/ Windows 11。x64 版と ARM64 版があります。.NET などの追加インストールは不要です。

## 入手と起動

1. [GitHub のリリース](https://github.com/supergodak/fuseo/releases?q=win-v) から zip をダウンロードします
   - `Fuseo-win-<版>-x64.zip` … 一般的なパソコン（Intel / AMD）
   - `Fuseo-win-<版>-arm64.zip` … ARM 版 Windows（Snapdragon など）
2. zip を右クリック →「すべて展開」で、好きなフォルダに展開します（インストーラはありません）
3. 展開したフォルダの `Fuseo.exe` をダブルクリックします
4. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください
   （電子署名を付けていない無料ソフトのため、この表示が出ます）
5. 初回の起動は数秒かかることがあります

## 画面の見かた

- **上のツールバー**（アイコンと名前のボタン）
  - 新しい書類／ファイルを開く／フォルダを開く
  - 道具: **選択・矩形・ブラシ・文字**（選んでいる道具は青く表示されます。キーボードの V・R・B・T でも切り替え）
  - ブラシを選んでいるときだけ、太さ（細・中・太）が出ます
  - 元に戻す（Ctrl+Z）・やり直す（Ctrl+Y）・削除（Delete）
  - 左に回転（Ctrl+L）・右に回転（Ctrl+R）・切り抜き
  - 縮小・拡大・全体（Ctrl+ホイールでも拡大縮小）
  - 右端: 設定・バージョン情報・**書き出し**（青いボタン・Ctrl+E）
- **左**: ページの一覧。下のボタンで上へ・下へ・削除
- **右**: 書類の種類、この書類で普通伏せる欄、自動検出の候補（チェックで塗る／塗らない）、文字の一覧（文字があるとき）

## 基本の流れ

1. 画像（JPEG / PNG / BMP / TIFF）や PDF をウィンドウにドラッグするか、「ファイルを開く」で選びます
2. Windows 標準の文字認識（このパソコンの中だけで動きます）で書類の種類と向きを判定し、
   マイナンバー・運転免許証番号・保険証の記号番号・在留カード番号・QR コード・顔写真などを「自動検出の候補」に出します
3. 候補を確かめます。違うときは「書類の種類」を選び直し、足りない所は**矩形かブラシ**で塗ります
4. 「**書き出し**」で、書き出す画像そのもので仕上がりを確かめてから保存します

- 判定や検出は外れることがあります。氏名・住所などは自動では塗りません。保存する前に、必ず仕上がりをご自身で確かめてください
- 番号の自動検出には「日本語の文字認識」が必要です（日本語版 Windows には通常入っています）。
  入っていない場合は、設定 › 時刻と言語 › 言語 › 日本語 › 言語のオプション で追加できます（追加しなくても手で塗れます）
- HEIC（iPhone の写真）は、Microsoft Store の「HEIF 画像拡張機能」が入っている場合だけ開けます。開けない場合は iPhone 側で JPEG にしてください

## 切り抜き・回転

- 斜めに撮った写真は「**切り抜き**」で四隅を書類の角に合わせると、まっすぐに直せます
- 向きが違うときは「左に回転」「右に回転」。「文字を読み直す」で、向きを直したあとに番号を読み直せます
- 切り抜き・回転をすると、そのページで入れた文字は消えます（位置がずれるため）。先に向きと切り抜きを整えてください

## 書類に文字を入れる（記入）

申込書・申告書などに文字を打ち込めます（0.3 以降）。**どこに・どの大きさで打つかは自分で決めます**（欄やマスを自動で探す機能はありません）。

1. 道具の「**文字**」（T キー）を選び、書きたい欄の上をドラッグして枠を作ります（クリックだけなら標準の大きさの枠）
2. 枠の下に出る入力欄に打ち、**Enter で確定**します。改行は **Shift+Enter**、やめるときは **Esc**

右側の「文字」パネルで調整します。

- **書体**（游ゴシック・游明朝）、**サイズ**（pt）、**行間**（倍）、**字間**（文字サイズの何倍を足すか）
- **横・縦の揃え**、**マス数**（個人番号の 12 マス、郵便番号の 7 マスなど。1 マスに 1 文字ずつ並びます）
- **色**（黒・青・赤・緑・茶・灰の 6 色か、「その他」で好きな色）
- **位置と大きさ（mm・ページ左上から）**、「**枠の高さに合わせる**」（文字の大きさを 1 回だけ計算して入れます）

枠の操作: ドラッグで移動、つまみで大きさ変更、**矢印キーで 1 ピクセル**（Shift で 10）、Ctrl+D で複製、Delete で削除、ダブルクリックで打ち直し。
ほかの枠と端がそろうと吸い付きます（Ctrl を押しながらだと吸い付きません）。文字が枠からはみ出すと、枠が赤い点線になります。
一度変えた設定は次の枠にも引き継がれます（マス数を除く）。

- 打った文字も画像に焼き込まれ、**黒塗りは文字より上**に塗られます（伏せた所に文字は残りません）
- 文字を入れた作業は 0.2 以前の Fuseo では開けません
- 書き出したファイルは、あとから文字だけ直せません。直すときは「作業中の書類」から開き直して、書き出し直してください

## フォルダの一括処理

- フォルダをドラッグするか「フォルダを開く」で、中の書類をまとめて取り込みます（画像と PDF のページを合わせて **50 ページ**まで）
- 「**一覧**」で全ページを見渡せます。マスクが 1 つもないページには赤い「マスクなし」が付きます。セルを選ぶとそのページに戻ります
- 複数の書類を開いているときは、書き出しの「**書類ごとに分ける**」で、書類ごとに「元の名前-masked」として保存できます
  （同じ名前があれば -2, -3 … を付け、既存のファイルは上書きしません）

## 書き出し

- 形式は PDF／JPEG／PNG。プレビューは書き出す画像そのもの（焼き込み済み）です
- 塗った部分は画素そのものが黒になり、元に戻せません。撮影日時などの情報（メタデータ）も書き出したファイルには入りません
- 画面には「マスク N 箇所」「文字 N 箇所」が出ます。文字が枠からはみ出していると注意が出ます
- Windows 版には、グレー・白黒での書き出しと検索可能 PDF はありません（Mac・iPhone 版の機能です）

## 作業中の書類（保存と再開）

- 作業は自動で保存され、最初の画面の「作業中の書類」から続きを開けます。書き出したあとも、削除するまで残ります
- 保存先: `%LOCALAPPDATA%\Fuseo\Library`（このパソコンの中だけ。黒塗り前の画像も含みます）。
  一覧から 1 件ずつ、または「設定」からまとめて削除できます
- 設定: `%LOCALAPPDATA%\Fuseo\settings.json`。レジストリは使いません

## 削除（アンインストール）

1. `Fuseo.exe`（展開したフォルダごと）を削除します
2. 作業中の書類と設定も消す場合は、`%LOCALAPPDATA%\Fuseo` フォルダを削除します
3. プログラムの部品の展開先 `%TEMP%\.net\Fuseo` も削除してかまいません（書類は入っていません）

## 改ざんの確認（任意）

PowerShell で `Get-FileHash .\Fuseo-win-<版>-x64.zip` を実行し、表示された値がリリースページの SHA-256 と一致すれば、
配布したままのファイルです（ARM64 版は `-arm64.zip`）。

## 知っておいてほしいこと

- 自動検出は完璧ではありません。保存前に必ず自分の目で確かめてください
- 原本の提出・保存が必要な書類は、黒塗りしたコピーで代わりにはできません。提出先の指示をご確認ください
- マイナンバーカードの裏面は、そもそも提出できない場面が多い書類です
- Fuseo.exe に含まれる Microsoft の部品（Windows SDK for .NET）は MIT の対象外で、Microsoft の Windows SDK のライセンス条項に従います
