# 文字入れ（書類に文字を打つ）設計 — Mac 0.3.0 → Windows 0.3 → iOS（Pro 候補）

**起草**: 2026-11-11（メイン＝Opus 5.5 の Fable 役）
**決定（2026-11-11 ユーザー）**: 作る（黒塗りが主役・文字入れは補助）／順番は Mac → Windows → iOS／iOS は Pro にするか Mac の反応を見て決める／
最初の版は縦書き・電子印鑑・前の入力の引き継ぎ・ラベル推測を入れない。
**重点（ユーザー指示）**: マスの位置などの自動認識は精度が上がらない前提。**どこに・どの大きさで打つかを手で正確に決められること**を最優先にする。
**必須（ユーザー指示）**: ①テキストの枠（位置・大きさ）②文字サイズ ③改行したときの行間 — の 3 つを調整できること。

参考: 市販の「まかせて位置合わせPDF」（Windows・3,980 円・要登録/ネット）。Fuseo は無料・登録不要・通信なし・黒塗りと一体、で並ぶ。

---

## 1. できること（0.3.0 の範囲）

- 道具に「文字」を足す（選択・矩形・ブラシ・**文字**）。
- **枠を描いて打つ**: ページ上をドラッグして枠（＝書く欄）を作り、そのまま文字を打つ。クリックだけなら既定の大きさの枠ができる。
- **枠**: ドラッグで移動・8 か所のつまみで大きさ変更。矢印キーで 1px、⇧+矢印で 10px 動かす。数値でも指定できる（位置・幅・高さ、mm）。
- **文字サイズ**: pt で指定（数値入力とステッパー、0.5pt 刻み、4〜72pt）。「枠の高さに合わせる」ボタン（1 回だけ計算して値を入れる。自動で追従はしない）。
- **行間**: 改行（⌥Return）した複数行の行と行の間隔を **倍率**で指定（0.8〜3.0・0.05 刻み、既定 1.2）。数値入力とステッパー。
- **横の揃え**: 左・中央・右。**縦の揃え**: 上・中央・下（既定は中央＝表の欄に枠を合わせれば行の真ん中に来る）。
- **マス目**: 「マス数 N」を指定すると、枠の幅を N 等分して 1 マスに 1 文字ずつ中央に置く（個人番号 12 桁・郵便番号 7 桁・日付など）。
  マスの位置は**枠の幅と左右の端で手で合わせる**（自動でマスを探さない）。N=0（既定）は通常の文章。マス目のときは 1 行だけ。
- **書体**: ゴシック・明朝。**色**: 黒・青（青はボールペン風）。
- 複製（⌘D・少しずらして複製）、削除（Delete）、⌘Z で元に戻す（作成・移動・大きさ・文字・設定のそれぞれが 1 手）。
- **前に使った設定を次の枠に引き継ぐ**（書体・サイズ・行間・揃え・色。文字そのものは引き継がない）。
- はみ出し表示: 文字が枠に収まらないとき、編集中の画面で枠を赤い破線にする（書き出しは切り取らずにそのまま描く）。
- 位置合わせの補助（手作業を助けるだけ・自動配置はしない）: 他の文字枠と左端・右端・行の中心が揃ったら細い線を出して吸い付く（⌘ を押しながら動かすと吸い付かない）。

**入れないもの（0.3.0）**: 縦書き、電子印鑑、マス・罫線の自動検出、ラベル（「氏名」など）を読んでの自動配置、入力内容の引き継ぎ、字間の任意指定（マス目以外）、
文字の一部だけの書式変更、検索可能 PDF のテキスト層への入力文字の追加。

## 2. 正しさの要件（黒塗りとの関係）

- **焼き込み順は 基準画像 → 文字 → マスク（候補・手動矩形）→ ブラシ**。マスクは常に文字の上。個人番号を打ってから伏せても、伏せた所に文字の画素は残らない。
  （テスト: 文字の上に矩形マスク → マスク内の全画素が完全不透明の黒）
- 文字もラスタに焼き込む（注釈・フォーム・テキストオブジェクトにしない）。検索可能 PDF のテキスト層は従来どおり OCR からだけ作り、入力文字は入れない。
- 保存前の確認画面はそのまま。書き出しの確認に「文字 N か所」を足す（書いた量の確認）。
- 書き出しに入力文字以外のもの（書体名など）を残さない。PDF の /Info は Producer のみ（0.2.4 の仕組みのまま）。
- 入力した文字は作業ライブラリ（端末内のみ）に保存する。ログに文字の中身を出さない。

## 3. データ（コア）

```swift
/// 文字枠 1 つ。座標は基準画像の正規化（左下原点・CoordinateSpace 規約どおり）。
public struct TextBox: Codable, Sendable, Equatable, Identifiable {
    public var id: UUID
    public var box: NormRect            // 枠（位置と大きさ）
    public var text: String             // 改行 \n を含んでよい
    public var fontSizePt: Double       // 書き出し 300dpi 換算の pt（px = pt × 300 / 72）
    public var lineSpacing: Double      // 行の送り＝fontSize × lineSpacing（既定 1.2）
    public var font: Font               // .gothic / .mincho
    public var color: Color             // .black / .blue
    public var hAlign: HAlign           // .left / .center / .right
    public var vAlign: VAlign           // .top / .center / .bottom
    public var cells: Int               // 0 = 通常、N ≥ 1 = マス目（1 行）
}
```

- `AnalyzedPage.texts: [TextBox]`（ManualMask とは別。マスク数・「マスクの無いページ」警告には数えない）。
- **文字サイズを pt（300dpi 換算）で持つ理由**: 0.2.4 で PDF の紙を 300dpi 換算に揃えたので、PDF から取り込んだ書類では画面の pt＝印刷の pt になる。
  写真の取り込みは紙の大きさが推定なので「目安の pt」になる（UI に注記しない。枠に合わせるボタンで足りる）。
- 種別の変更（再解析）では文字枠を保持する（手動マスクと同じ）。**切り抜き・回転は基準画像が変わるので破棄**し、
  そのとき既存の確認（`hasUserEdits`）に文字枠も数える（「文字も消えます」と分かる文言にする）。
- ページの削除・並べ替えではページと一緒に動く（0.2.3 の仕組み）。

### 保存形式（WorkDocument）

- `WorkPage.texts: [TextBox]`（無ければ空として読む）。
- **文字枠が 1 つでもある作業は `schemaVersion = 2` で書く。無ければ 1 のまま**。
  古い版（0.2.x）は未知の版を拒否するので、文字入りの作業を古い版で開いて保存し、文字が黙って消える事故が起きない。
  文字の無い作業は古い版でもそのまま開ける。読み込み側は 1 と 2 を受け付ける。ゴールデンテストを 2 用に 1 つ足す。

## 4. 描画（コア）

- `TextBoxRenderer`（CoreText）: 枠と設定から行ごとの位置を決めて CGContext に描く。**画面表示と焼き込みで同じ関数**を使い、見た目と出力をずらさない。
  - 書体: ゴシック＝ヒラギノ角ゴシック W3、明朝＝ヒラギノ明朝 ProN W3（macOS・iOS とも標準）。
  - 通常: 改行で行に分け、**枠の幅で自動折り返しはしない**（打った改行だけが改行。手で決める方針）。行の送り＝fontSize×lineSpacing。
    行の塊の高さ＝(行数−1)×送り＋1 行の高さ（ascent+descent）。縦の揃えはこの塊を枠に対して置く。横の揃えは行ごと。
  - マス目: 枠の幅/N をマス幅とし、i 文字目をマス i の中心に置く（N を超えた文字は描かない＝はみ出し扱いで赤枠）。縦は vAlign。
  - はみ出し判定（`overflows`）: 塊の幅か高さが枠を超える、またはマス目で文字数 > N。画面の赤破線と書き出しの確認に使う。
  - 「枠の高さに合わせる」: 行数と行間から、塊の高さが枠の高さの 90% になる fontSize を逆算（0.5pt 単位に丸め・4〜72pt）。
- `RasterMaskRenderer.burnIn` に `texts` を足し、基準画像の直後・マスクの前に描く。

## 5. 画面（Mac）

- ツールバーに「文字」（`T` のアイコン）。キーボード: V=選択、R=矩形、B=ブラシ、**T=文字**（既存にキー割り当てが無ければ足さない・要確認）。
- 文字ツールでドラッグ → 枠ができて編集状態。**入力欄は枠のすぐ下（下に余地が無ければ上）に普通の文字で出し、枠の中には焼き込みと同じ描画を毎回出す**（F2 実装時に変更: 入力欄を枠に重ねると書体・揃え・行間・マス目が描画とずれるため）。Return で確定、⌥Return で改行、Esc で取り消し（空なら枠も消す）。
- 選択ツールで文字枠をクリック → 選択（つまみ表示）、ダブルクリックで編集。
- 右の候補リストの上に「文字」パネル（選択中の枠の設定）: 書体・サイズ（pt）・行間（倍）・横/縦の揃え・マス数・色・位置と大きさ（mm）・「枠の高さに合わせる」。
  何も選んでいないときは「次に作る枠の設定」を編集する（前に使った設定の引き継ぎと同じ値）。
- 一覧表示（グリッド）では文字も描く（編集はしない）。
- 書き出しプレビュー（マスクのみ表示）でも文字は表示する（出力と同じ見た目）。

## 6. テスト

- コア: TextBox の Codable・schemaVersion 1/2 の書き分けと読み込み・ゴールデン、描画（指定位置にインクが出る／揃え・行間で行の位置が変わる／
  マス目の各文字がマスの中心／はみ出し判定／枠に合わせるの逆算）、焼き込み順（文字の上のマスクは全黒）、書き出し PDF に文字のテキストが無い。
- Mac アプリ層: 作成・移動・大きさ・文字・設定の Undo、種別変更で保持・回転/切り抜きで破棄（確認あり）、ページ削除/並べ替えで追従、保存→開き直しで同じ、
  設定の引き継ぎ。UI テスト 1〜2 件（文字ツールで枠を作って打つ → 書き出しまで）。
- 目視: 合成の申告書ふう PDF（マス目の個人番号欄・氏名欄・住所 2 行）で打つ → 書き出して紙の大きさ・位置・行間を確認（実物書類は使わない）。
