# Fuseo（ふせお）使い方ガイド

**Fuseo は、本人確認書類の写真や証明書の PDF を「提出してよい状態」にするアプリです。**
マイナンバーや免許証番号など、提出先に見せる必要のない部分を自動で見つけて黒塗りし、
きれいなスキャン風の PDF や画像として保存します。Mac・Windows・iPhone で使えます（どれも無料）。

| 端末 | 使い方 |
|---|---|
| **Mac** | このページ |
| **Windows** | [Windows 版の使い方](user-manual-windows.md) |
| **iPhone・iPad** | [iPhone 版の使い方](user-manual-ios.md) |

端末ごとにできることの違いと画面は「[機能のご紹介](https://fuseo.ati-mirai.co.jp/features.html)」にまとめています。
以下は **Mac 版**（macOS 14 以降）の使い方です。

## Fuseo の3つの安心

1. **完全ローカル** — 写真がインターネットに送られることは一切ありません。すべてお使いの端末の中だけで処理されます。アカウント登録も不要です。
2. **消したところは復元できません** — 黒塗りは画像そのものを塗りつぶす方式です。iPhone のマーカーペンのように「あとから透けて見える」ことはありません。
3. **勝手に保存しません** — 黒塗りする場所は必ずあなたが画面で確認してから保存します。

## 対応している書類

| 書類 | 自動で黒塗り候補になる箇所（例） |
|---|---|
| マイナンバーカード（表） | 性別欄・臓器提供意思欄 |
| マイナンバーカード（裏） | 個人番号（12桁）・QRコード |
| 運転免許証（表） | 免許証番号 |
| 運転免許証（裏） | 臓器提供意思表示欄（備考欄は残します） |
| 在留カード（表） | 在留カード番号 |
| 健康保険証・資格確認書・住民票 | 記号・番号・個人番号など（対応拡充中） |

上記以外の書類も読み込めます。その場合は自動候補が出ないことがありますが、手動ツールで自由に塗れます。

## 基本の流れ（5ステップ）

1. **Fuseo を起動** — アプリケーションフォルダの Fuseo をダブルクリック
2. **写真や PDF を読み込む** — 書類の写真や PDF をウィンドウに**ドラッグ＆ドロップ**するか、「ファイルを選択…」をクリック
   - 対応形式: JPEG / PNG / HEIC / TIFF / PDF（iPhone で撮った写真はそのまま使えます。AirDrop で Mac に送るのが手軽です）
   - 複数枚まとめてもOK（あとで1つの PDF にできます）。フォルダごとでも読み込めます（→「一括処理」）
3. **確認する** — 自動で「書類の切り抜き・傾き補正・種別判定・黒塗り候補の検出」まで進みます。
   候補が正しいか、画面で必ず確認してください
4. **調整する** — 塗りたくない候補はチェックを外す。足りないところは手動で塗り足す
5. **書き出す** — 「書き出す…」ボタン → 形式を選んで保存。できたファイルを提出に使います

## 確認画面の見かた

写真を読み込むと、左に書類のプレビュー、右に情報パネルが表示されます。

【右パネル】

■ 種別
  - 自動判定された書類の種類が表示されます。間違っていたらここで選び直せます
■ 黄色い注意書き（表示される場合）
  - 例: マイナンバーカードの裏面は「そもそも提出が必要か確認を」など、
    その書類ならではの注意点です。一度目を通してください
■ マスク候補
  - 自動で見つかった黒塗り候補の一覧。チェックＯＮ＝塗る、ＯＦＦ＝塗らない
  - 各候補の下の小さな文字は「なぜここを塗るのか」の根拠です
  - 顔写真は最初はＯＦＦです（提出先によっては顔が必要なため）。
    隠したい場合はチェックを入れてください
  - **「（位置推定）」と付いた候補**は、光の反射などで番号そのものが読み取れなかったため、
    書類の規格上の位置から推定して広めに塗るものです。番号がはみ出していないか特に確認してください

【プレビュー上の表示】

■ 黒っぽい四角 … 塗る予定の場所（チェックＯＮの候補）
■ 灰色の点線の四角 … 見つかったけれど塗らない場所（チェックＯＦＦ）
  - プレビュー上の四角をダブルクリックしてもＯＮ／ＯＦＦを切り替えられます

## PDF を読み込む

保険料控除証明書・残高証明書など、電子で届く PDF もそのまま読み込めます。

- 各ページを画像として扱い、黒塗りした所の下に文字のデータは残りません
- ページの中に小さく写ったカード（スキャンした免許証など）は、自動で切り抜きます
- 一度に読み込めるのは、PDF のページと画像を合わせて **50 ページ**までです
- ページ数の多い PDF では「文字認識をしますか？」と聞かれます。文字認識をしないと速く読み込めますが、
  番号の自動検出・書類の種類の判定・検索可能 PDF は使えません（顔・QR コードの検出と手で塗るのは使えます）
- パスワード付きの PDF は、読み込むときにパスワードを聞かれます

## ページの削除・並べ替え

複数ページのときは、左のページ一覧で操作できます。

- 一覧の下のボタン: **↑（前へ）・↓（後ろへ）・ゴミ箱（削除）**。選んでいるページが動きます
- サムネイルを**右クリック**しても「前へ移動」「後ろへ移動」「このページを削除」が選べます（一覧表示でも使えます）
- **⌘Z** で元に戻せます（消したページも塗った所ごと戻ります）。最後の 1 ページは削除できません

## 塗りの位置・大きさを調整する

自動で見つかった黒塗りも、手動で描いた黒塗りも、あとから自由に調整できます。

1. ツールが「選択」（矢印アイコン）になっていることを確認
2. 調整したい黒塗りをクリックして選択 → 四隅に**小さな白い四角（ハンドル）**が出ます
3. **枠の中をドラッグ＝移動**、**ハンドルをドラッグ＝大きさ変更**。⌘Z で元に戻せます
4. 削除したいとき: 自動候補は右パネルのチェックを外す（Deleteキーでも外れます）。
   手動の塗りは Delete キーか右パネルの削除ボタン

## 手動で塗り足す

自動で見つからなかった箇所は、ツールバーのツールで自由に塗れます。

- **矩形**（点線の四角アイコン）: ドラッグした範囲を四角く塗ります
- **ブラシ**（筆アイコン）: なぞったところを塗ります。横のスライダーで太さを変えられます
- 塗り間違えたら **⌘Z** で取り消し。右パネルの「手動マスク」一覧からも削除できます
- 細かい場所は「100%」ボタンやズームスライダーで拡大してから塗ると正確です（「全体」で元に戻ります）

## 書類に文字を入れる（記入）

スキャンした申込書・申告書などに、パソコンで文字を打ち込めます。**どこに・どの大きさで打つかは自分で決めます**（欄やマスを自動で探す機能はありません）。

1. ツールバーの「**文字**」（「あぁ」のアイコン）を選びます
2. 書きたい欄の上を**ドラッグして枠**を作ります（クリックだけなら標準の大きさの枠ができます）
3. 下に出る入力欄に文字を打ち、**Return で確定**します。改行したいときは **⌥（option）＋Return**、やめるときは **Esc**

**枠・文字の大きさ・行間を整える**（右パネルの「文字」）

- **枠**: ドラッグで移動、四隅と辺のつまみで大きさを変えます。**矢印キーで 1 ピクセル**（⇧ を押しながらで 10 ピクセル）ずつ動かせます。
  「位置と大きさ」に **mm で数字を入れる**と、ページの左上からの位置と幅・高さをぴったり指定できます
- **サイズ**: 文字の大きさ（pt）。「**枠の高さに合わせる**」を押すと、枠の高さに収まる大きさを 1 回だけ計算して入れます
- **行間**: 改行したときの行と行の間隔（文字の大きさの何倍か）。住所を 2 行で書くときなどに使います
- **横・縦**: 枠の中での揃え（左・中央・右／上・中央・下）。表の欄に枠を合わせて「縦＝中央」にすると、行の真ん中に来ます
- **マス数**: 個人番号（12 マス）や郵便番号（7 マス）のようなマス目の欄では、マス数を入れると 1 マスに 1 文字ずつ並びます。
  **枠の左右の端をマスの両端に合わせてください**
- **字間**: 文字と文字の間隔（文字の大きさの何倍を足すか。0 が標準、0.5 で半文字分あきます）。マス目の欄では使いません
- **書体**（ゴシック／明朝）と**色**も選べます。色は 6 色（黒・青・赤・緑・茶・灰）から選ぶか、「その他」で好きな色を選べます。一度変えた設定は、次に作る枠にも引き継がれます
- ほかの文字の枠と端がそろうと細い線が出て吸い付きます（⌘ を押しながら動かすと吸い付きません）
- 文字が枠からはみ出すと、枠が**赤い点線**になります（そのまま保存もできます）
- 複製は **⌘D**、削除は **Delete**、取り消しは **⌘Z**

**知っておいてほしいこと**

- 打った文字も画像に焼き込まれます。**黒塗りは文字より上に塗られる**ので、個人番号を書いてから伏せても、伏せた所に文字は残りません
- 打った文字は、検索可能 PDF の検索対象には入りません
- **切り抜きの調整・回転をすると、そのページの文字は消えます**（位置がずれるため）。先に切り抜き・向きを整えてから記入してください
- 文字を入れた作業は、古い版（0.2.x）の Fuseo では開けません
- **書き出したファイル（PDF・画像）は、あとから文字だけ直すことはできません**（文字も黒塗りも画像に焼き込むため）。
  直したいときは、最初の画面の「**作業中の書類**」から同じ作業を開き直して、直してからもう一度書き出してください（書き出した作業も、削除するまで残っています）

## 切り抜きがおかしいとき（手動調整）

写真の写りによっては、書類の切り抜きが変な台形になることがあります。そのときは手動で直せます。

1. 右パネルの「**切り抜きを調整…**」をクリック（切り抜きに失敗したときは画面上部のバナーからも開けます）
2. 元の写真が表示され、四隅に**丸いハンドル**が出ます。書類の四つ角に合うようにドラッグしてください
   - 「**全体を使う**」: 切り抜きをやめて写真全体をそのまま使います
   - 「**自動検出に戻す**」: ハンドルを自動検出の位置に戻します
3. 「**適用**」をクリックすると、指定した範囲で切り抜き・補正・黒塗り候補の検出をやり直します

※ 適用すると、そのページで行った手動の塗り・入れた文字・チェックの変更はリセットされます（切り抜きが変わると位置がずれてしまうため）。先に切り抜きを直してから、塗りの調整をするのがおすすめです。

## 仕上がりプレビュー

ツールバー右の**目のアイコン**をオンにすると、実際に保存されるとおりの「真っ黒に塗りつぶした状態」を確認できます。保存前に一度見ておくのがおすすめです。

## たくさんの書類をまとめて処理する（一括処理）

書類が束である場合は、**フォルダごとドラッグ＆ドロップ**（または「ファイルを選択…」でフォルダを選択）できます。

1. フォルダを放り込むと、中の画像（1階層下まで）を名前順にすべて解析します
2. 5枚以上のときは**一覧表示**で始まります。各書類のサムネイルに「種別・マスク数・警告」が
   表示され、**マスクが1つもない書類には赤い「マスクなし」印**が付きます
3. 気になる書類をクリックすると個別の確認画面で調整できます（ツールバーのボタンで一覧⇄個別を切替）
4. 書き出しシートで「**書類ごとに個別ファイル**」を選ぶと、保存先フォルダに
   各書類が「元のファイル名-masked」で一括保存されます（同名があれば -2, -3…）

※一覧はあくまで「確認の入口」です。中身を見ずに自動保存する機能は、安全のため用意していません。

## 作業中の書類（保存と再開）

作業は自動で保存されます。途中で閉じても、最初の画面の「**作業中の書類**」から続きを開けます。

- 書き出したあとの作業も、削除するまで残ります。開き直せば、塗りを足したり、打った文字を直したりして書き出し直せます
- 一覧の「開く」「Finder で表示」「削除（ゴミ箱）」で操作します。まとめて消すときは 設定 → 「すべての作業を削除」
- 保存先はこの Mac の中だけです（iCloud などのバックアップ対象外・外部には送りません）。黒塗り前の画像も含まれるので、
  不要になった作業は削除してください

## 書き出し（保存）

1. ツールバー右上の「**書き出す…**」をクリック
2. 表示されるシートで以下を選びます
   - **形式**: PDF（提出用の定番）／ JPEG ／ PNG
   - **カラー**: カラー ／ グレー ／ 白黒（文書）— 白黒はスキャナの「文書モード」のような
     くっきりした二値になります（しきい値は自動）。どれを選んでも黒塗りは黒のままです
   - **検索可能PDF**: PDF内の文字を検索できるようにします（黒塗りした部分の文字は入りません）
   - **JPEG品質**: JPEG選択時のみ
   - シートには「マスク○箇所（自動○・手動○）／○ページ」の要約と注意書きも表示されます
3. 「保存…」→ 保存場所と名前を決めて完了。ファイル名は最初「元のファイル名-masked」になります
4. 保存が終わると「Finderで表示」ボタンが出ます。続けて別の書類を処理するときは「新しい書類」をクリック

- 複数ページをPDFで書き出すと**1つのファイル**にまとまります。JPEG/PNG の場合は「名前-1.jpeg」「名前-2.jpeg」…と分かれます
- **マスクが1つもないページがあると赤字で警告**が出ます。そのまま保存もできますが、元の情報が全部残る点にご注意ください

## 設定（メニューバーの Fuseo → 設定）

- **書き出しの既定値**: 形式（PDF/JPEG/PNG）・検索可能PDF・JPEG品質の初期値
- **スキャン風仕上げ強度**: 住民票などの紙書類の影を消して白背景に整える強さ。カード類（免許証・マイナンバーカード）には適用されません
- **顔写真を既定でマスクする**: オンにすると、検出された顔写真が最初からチェックＯＮになります（個別に外せます）
- **作業中の書類**: 保存されている作業をすべて削除できます（元に戻せません）

## 知っておいてほしいこと

- **自動検出は完璧ではありません。** 保存前に必ず自分の目で「塗るべき場所が塗られているか」を確認してください。塗り漏れの最終確認はご自身でお願いします
- **マイナンバーカードの裏面は、そもそも提出できない場面が多い書類です**（法令で複写が制限されています）。提出を求められているのが本当に裏面なのか、先に確認してください
- **原本の提出・保存が必要な書類**は、黒塗りしたコピーで原本の代わりにはできません。提出先の指示に従ってください（文字入れで作った書類も同じです）
- 元の写真ファイルはそのまま残ります。提出後は、元の写真自体の取り扱い（削除など）にもご注意ください
- 書き出したファイルには撮影日時・位置情報などのメタデータは引き継がれません

## 困ったとき

- **「書類の輪郭を検出できませんでした」と出る／変な形に切り抜かれる**
  → バナーまたは右パネルの「切り抜きを調整…」で四隅を手動指定できます。書類が画面いっぱいに写るように撮り直すのも有効です（背景と書類の色にコントラストがあると検出しやすくなります）
- **書類の向きが横倒し・逆さまになる**
  → 向きは自動判定していますが、外れることがあります。ツールバーの**回転ボタン**（右回りの矢印）を
  押すたびに90°ずつ回転して解析し直します
- **種別が違うと表示される**
  → 右パネルの「種別」から正しいものを選んでください。選び直すと候補が検出し直されます（手動で塗った分は残ります）
- **候補が1つも出ない**
  → 未対応の書類か、文字がうまく読み取れていません。手動ツール（矩形・ブラシ）で塗ってください
- **PDF が読み込めない・ページが足りない**
  → 一度に読み込めるのは合計 50 ページまでです。長い書類は、必要なページだけを PDF に書き出してから読み込んでください。
  パスワード付きの PDF は、正しいパスワードを入れると読み込めます
- **申告書などの PDF が「マイナンバーカード」と判定される**
  → 0.3.0 で直しました。最新版に更新してください。古い版では右パネルの「種別」で「その他の書類」を選び直してください
