# Fuseo（ふせお）使い方ガイド

**Fuseo は、本人確認書類の写真を「提出してよい状態」にする Mac アプリです。**
マイナンバーや免許証番号など、提出先に見せる必要のない部分を自動で見つけて黒塗りし、
きれいなスキャン風の PDF や画像として保存します。

## Fuseo の3つの安心

1. **完全ローカル** — 写真がインターネットに送られることは一切ありません。すべてお使いの Mac の中だけで処理されます。アカウント登録も不要です。
2. **消したところは復元できません** — 黒塗りは画像そのものを塗りつぶす方式です。iPhone のマーカーペンのように「あとから透けて見える」ことはありません。
3. **勝手に保存しません** — 黒塗りする場所は必ずあなたが画面で確認してから保存します。

## 対応している書類

| 書類 | 自動で黒塗り候補になる箇所（例） |
|---|---|
| マイナンバーカード（表） | 性別欄・臓器提供意思欄 |
| マイナンバーカード（裏） | 個人番号（12桁）・QRコード |
| 運転免許証（表） | 免許証番号 |
| 運転免許証（裏） | 臓器提供意思表示欄（備考欄は残します） |
| 健康保険証・資格確認書・住民票 | 記号・番号・個人番号など（対応拡充中） |

上記以外の書類も読み込めます。その場合は自動候補が出ないことがありますが、手動ツールで自由に塗れます。

## 基本の流れ（5ステップ）

1. **Fuseo を起動** — アプリケーションフォルダの Fuseo をダブルクリック
2. **写真を読み込む** — 書類の写真をウィンドウに**ドラッグ＆ドロップ**するか、「ファイルを選択…」をクリック
   - 対応形式: JPEG / PNG / HEIC / TIFF（iPhone で撮った写真はそのまま使えます。AirDrop で Mac に送るのが手軽です）
   - 複数枚まとめてもOK（あとで1つの PDF にできます）
3. **確認する** — 自動で「書類の切り抜き・傾き補正・種別判定・黒塗り候補の検出」まで進みます。
   候補が正しいか、画面で必ず確認してください
4. **調整する** — 塗りたくない候補はチェックを外す。足りないところは手動で塗り足す
5. **書き出す** — 「書き出す…」ボタン → 形式を選んで保存。できたファイルを提出に使います

## 確認画面の見かた

写真を読み込むと、左に書類のプレビュー、右に情報パネルが表示されます。

【右パネル】

■ 種別
  - 自動判定された書類の種類が表示されます。間違っていたらここで選び直せます
■ 黄色い注意書き（表示される場合）
  - 例: マイナンバーカードの裏面は「そもそも提出が必要か確認を」など、
    その書類ならではの注意点です。一度目を通してください
■ マスク候補
  - 自動で見つかった黒塗り候補の一覧。チェックＯＮ＝塗る、ＯＦＦ＝塗らない
  - 各候補の下の小さな文字は「なぜここを塗るのか」の根拠です
  - 顔写真は最初はＯＦＦです（提出先によっては顔が必要なため）。
    隠したい場合はチェックを入れてください
  - **「（位置推定）」と付いた候補**は、光の反射などで番号そのものが読み取れなかったため、
    書類の規格上の位置から推定して広めに塗るものです。番号がはみ出していないか特に確認してください

【プレビュー上の表示】

■ 黒っぽい四角 … 塗る予定の場所（チェックＯＮの候補）
■ 灰色の点線の四角 … 見つかったけれど塗らない場所（チェックＯＦＦ）
  - プレビュー上の四角をダブルクリックしてもＯＮ／ＯＦＦを切り替えられます

## 塗りの位置・大きさを調整する

自動で見つかった黒塗りも、手動で描いた黒塗りも、あとから自由に調整できます。

1. ツールが「選択」（矢印アイコン）になっていることを確認
2. 調整したい黒塗りをクリックして選択 → 四隅に**小さな白い四角（ハンドル）**が出ます
3. **枠の中をドラッグ＝移動**、**ハンドルをドラッグ＝大きさ変更**。⌘Z で元に戻せます
4. 削除したいとき: 自動候補は右パネルのチェックを外す（Deleteキーでも外れます）。
   手動の塗りは Delete キーか右パネルの削除ボタン

## 手動で塗り足す

自動で見つからなかった箇所は、ツールバーのツールで自由に塗れます。

- **矩形**（点線の四角アイコン）: ドラッグした範囲を四角く塗ります
- **ブラシ**（筆アイコン）: なぞったところを塗ります。横のスライダーで太さを変えられます
- 塗り間違えたら **⌘Z** で取り消し。右パネルの「手動マスク」一覧からも削除できます
- 細かい場所は「100%」ボタンやズームスライダーで拡大してから塗ると正確です（「全体」で元に戻ります）

## 切り抜きがおかしいとき（手動調整）

写真の写りによっては、書類の切り抜きが変な台形になることがあります。そのときは手動で直せます。

1. 右パネルの「**切り抜きを調整…**」をクリック（切り抜きに失敗したときは画面上部のバナーからも開けます）
2. 元の写真が表示され、四隅に**丸いハンドル**が出ます。書類の四つ角に合うようにドラッグしてください
   - 「**全体を使う**」: 切り抜きをやめて写真全体をそのまま使います
   - 「**自動検出に戻す**」: ハンドルを自動検出の位置に戻します
3. 「**適用**」をクリックすると、指定した範囲で切り抜き・補正・黒塗り候補の検出をやり直します

※ 適用すると、そのページで行った手動の塗りやチェックの変更はリセットされます（切り抜きが変わると位置がずれてしまうため）。先に切り抜きを直してから、塗りの調整をするのがおすすめです。

## 仕上がりプレビュー

ツールバー右の**目のアイコン**をオンにすると、実際に保存されるとおりの「真っ黒に塗りつぶした状態」を確認できます。保存前に一度見ておくのがおすすめです。

## 書き出し（保存）

1. ツールバー右上の「**書き出す…**」をクリック
2. 表示されるシートで以下を選びます
   - **形式**: PDF（提出用の定番）／ JPEG ／ PNG
   - **カラー**: カラー ／ グレー ／ 白黒（文書）— 白黒はスキャナの「文書モード」のような
     くっきりした二値になります（しきい値は自動）。どれを選んでも黒塗りは黒のままです
   - **検索可能PDF**: PDF内の文字を検索できるようにします（黒塗りした部分の文字は入りません）
   - **JPEG品質**: JPEG選択時のみ
   - シートには「マスク○箇所（自動○・手動○）／○ページ」の要約と注意書きも表示されます
3. 「保存…」→ 保存場所と名前を決めて完了。ファイル名は最初「元のファイル名-masked」になります
4. 保存が終わると「Finderで表示」ボタンが出ます。続けて別の書類を処理するときは「新しい書類」をクリック

- 複数ページをPDFで書き出すと**1つのファイル**にまとまります。JPEG/PNG の場合は「名前-1.jpeg」「名前-2.jpeg」…と分かれます
- **マスクが1つもないページがあると赤字で警告**が出ます。そのまま保存もできますが、元の情報が全部残る点にご注意ください

## 設定（メニューバーの Fuseo → 設定）

- **書き出しの既定値**: 形式（PDF/JPEG/PNG）・検索可能PDF・JPEG品質の初期値
- **スキャン風仕上げ強度**: 住民票などの紙書類の影を消して白背景に整える強さ。カード類（免許証・マイナンバーカード）には適用されません
- **顔写真を既定でマスクする**: オンにすると、検出された顔写真が最初からチェックＯＮになります（個別に外せます）

## 知っておいてほしいこと

- **自動検出は完璧ではありません。** 保存前に必ず自分の目で「塗るべき場所が塗られているか」を確認してください。塗り漏れの最終確認はご自身でお願いします
- **マイナンバーカードの裏面は、そもそも提出できない場面が多い書類です**（法令で複写が制限されています）。提出を求められているのが本当に裏面なのか、先に確認してください
- **原本の保存が義務づけられている書類**（扶養控除等申告書など）は、黒塗りしたコピーで代替できません。Fuseo の対象外です
- 元の写真ファイルはそのまま残ります。提出後は、元の写真自体の取り扱い（削除など）にもご注意ください
- 書き出したファイルには撮影日時・位置情報などのメタデータは引き継がれません

## 困ったとき

- **「書類の輪郭を検出できませんでした」と出る／変な形に切り抜かれる**
  → バナーまたは右パネルの「切り抜きを調整…」で四隅を手動指定できます。書類が画面いっぱいに写るように撮り直すのも有効です（背景と書類の色にコントラストがあると検出しやすくなります）
- **種別が違うと表示される**
  → 右パネルの「種別」から正しいものを選んでください。選び直すと候補が検出し直されます（手動で塗った分は残ります）
- **候補が1つも出ない**
  → 未対応の書類か、文字がうまく読み取れていません。手動ツール（矩形・ブラシ）で塗ってください
- **PDFをドロップしたのに読み込めない**
  → 現在の対応は画像（JPEG / PNG / HEIC / TIFF）のみです。PDFはスクリーンショット等で画像にしてから読み込んでください
